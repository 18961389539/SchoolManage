# 需求与验收矩阵

## 范围依据

来源是用户提供的两张图片：第一张从“1. 平台基础功能”开始，第二张在“1.3.3 虚拟机信息”开头被截断。可完整识别 11 项功能，无法据此推定整个平台的全部课程、AI/GPU、实验编排或虚拟机生命周期需求。

用户随后确认的交付约束：

1. 实际部署并交付学校使用。
2. 部署机为 Windows 11；不采用容器，除发布程序外尽量少安装软件。
3. 暂无真实机柜/串口控制器，使用模拟设备。
4. 暂无虚拟化平台，先采用内置模拟节点和虚拟机，不启用额外系统功能。
5. 时间与网络配置在模拟节点上实现；Windows 11 管理主机只读采集，不变更真实系统时间或网卡配置。

因此，本次可验证范围为 Windows 上业务系统、模拟设备操作闭环、模拟节点时间/网络配置及模拟资源生命周期。真实串口控制器、跳板链路和生产虚拟化平台兼容性独立列为将来接入项，不将模拟结果描述为真实设备测试。

## 导入验收细化

教师与学生导入同时验证：

- 可下载模板并导入约定格式，限制文件大小、行数和字段长度。
- 预览待导入数据，指出具体行号、列名和问题说明。
- 校验必填、重复账号/工号/学号、无效班级、联系方式等。
- “一键移除问题数据”只针对当前待导入批次的错误行，不删除已有师生数据。
- 保留有效行提交后，重复提交不会重复建账号；提交前再次校验并发产生的重复数据。
- 初始密码通过受控输入设置，不在审计日志或接口列表泄露。
- 万行文件按页预览（默认 50 行/页，可切换 50/100/200），“仅看问题行”只过滤显示、不改变待导入数据；不一次性渲染全部行。
