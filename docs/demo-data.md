# 演示数据

本仓库不包含本机运行库（`.local/data/school.db`）或管理员密码。需要一套可演示平台功能的仿真数据时，请在已经完成管理员初始化、服务正在运行的前提下，用产品接口导入种子脚本。脚本可以重复执行：默认只追加尚不存在的演示记录，不会删除或覆盖使用者已有数据，也不会修改 `admin` 账号。

## 导入

先按 [README](../README.md) 在本机启动服务，并在 [http://127.0.0.1:5080](http://127.0.0.1:5080) 完成本地管理员初始化。然后在仓库根目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/seed-demo-data.ps1
```

脚本会提示输入当前管理员密码，也可事先设置环境变量 `SCHOOL_ADMIN_PASSWORD`。不要把该密码写入仓库或提交到 Git。可用 `-BaseUrl`、`-UserName` 指向其他本机实例，例如：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/seed-demo-data.ps1 -BaseUrl http://127.0.0.1:5080 -UserName admin
```

导入内容包括：

- 调用产品自带的「创建模拟环境」，生成模拟机柜、节点、交换机、路由器和模拟虚拟机（已存在时会保留原有配置）
- 追加模拟防火墙 FW-01、模拟工控主机 PC-01，以及「模拟液压实训环境」「模拟机器人示教环境」两台虚拟机；若接口允许，会启动已有的「模拟 Linux 实训环境」
- 3 个专业、4 个班级、3 名教师、15 名学生
- 1 个专业核心课系列，4 门已发布课程及其章节资源（含机械制图新增的剖视图章节，以及液压与气动技术）
- 若干小型演示附件（文本说明和示意图），运行时临时生成后通过产品接口上传，不会把附件二进制提交到 Git
- 4 个进行中课堂（含制图、电气联调和机器人等演示分组）；数控课堂会把模拟实训机柜分配给联调实操
- 1 个已结束课堂：「机电 2024 级液压与气动结课示范课堂」（含学习记录和联调实操评分，脚本不会关闭上述 4 个进行中课堂）
- 「机械制图理论题库」和「数控电气安全题库」、两份理论试卷、一场进行中的机械制图阶段测验，以及「2024 学年数控电气安全分析测验」（作答后结束，供成绩与试题分析演示）。脚本不会结束已有的制图测验。若「2024 学年数控电气安全测验」仍处于开考状态，脚本也会写入作答，但不会为了分析去结束它
- 「数控联调实操题库」和「数控联调实操测验卷」，以及已结束的「2024 学年数控联调实操评分测验」（含自动评分的实操题，脚本会先部署模拟环境再作答）
- 「数控机床调试员岗位训练营」和「工业机器人运维员岗位训练营」（若当前版本支持岗位发布，脚本会将其发布）
- 课堂学习记录与练习作答、考试作答、岗位训练营作答（成绩有高有低，制图测验中周明轩仅进入作答、不提交，便于查看进行中状态）
- 课堂案例实操评分与截图取证：脚本会为「模拟节点联调实操」「液压回路联调实操」补上评分表，学生按评分表配置模拟设备后提交终评，教师端写入演示截图。案例实操不能通过「完成学习」接口结束

学习记录、考试、训练营和实操作答通过学生账号调用产品接口写入。若学生仍处于「首次必须改密」状态，脚本会临时改密以便调用学习接口，导入结束后再由管理员重置接口恢复为演示初始密码，并重新打开「首次必须改密」。若某名学生的演示初始密码已经失效（例如本人已经改过），脚本会跳过该学生的活动，也不会重置其现有密码。

已存在的同名专业、班级、账号、课程、课堂、试卷、考试或岗位会被跳过，不会覆盖原有记录和口令；已提交的考试、已完成的学习记录和已终评的实操也不会重写。为已有案例实操资源补评分表时，只在评分表为空时写入，不会改资源名称、正文或学生记录。

## 安全约定

- 不要把 `.local/`、运行库、备份、密钥目录或构建产物提交到 Git。
- 若库中已有同名专业、班级、账号、课程、课堂、试卷、考试或岗位，脚本会跳过该项，保留现有记录和口令。
- 案例实操不能通过「完成学习」接口结束，需要按评分表配置模拟设备后提交终评；脚本不会伪造不符合接口的分数。
- 脚本不会关闭已存在的「2024 学年机械制图阶段测验」，也不会关闭已有的 4 个进行中课堂。若库中已有空的已结束「2024 学年数控电气安全测验」，或实操分为 0 的「2024 学年数控联调实操测验」，脚本也不会删除；新环境只创建可演示自动评分的「2024 学年数控联调实操评分测验」。已终评的实操会话不会再次调用「开始实操」，以免把已结束会话重新打开。制图测验中周明轩仅进入作答、脚本不会主动交卷；若作答时限到期，产品可能自动交卷。
